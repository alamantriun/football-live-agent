# Tipografía de la portada

La portada usa primero los fallbacks de sistema `Arial Narrow`, `Impact`, `Inter` y `Arial`.

La propuesta visual reserva Barlow Condensed para titulares y Barlow para lectura. Antes de incluir archivos WOFF2, se deben incorporar desde la distribución oficial de Google Fonts con su licencia SIL Open Font License (OFL) y registrar aquí la versión y la fuente exactas.
